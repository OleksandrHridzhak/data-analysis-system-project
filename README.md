## Лабораторні роботи

### [Лабораторна робота №1: Property Price ML PoC](lab1/)
- Реалізація концепту ML-застосунку для прогнозування вартості житлової нерухомості.
- Інтерактивний вебінтерфейс на Streamlit для введення характеристик об'єкта нерухомості та оцінки чутливості факторів ціноутворення.
- Набір тестів pytest (9/9 успішно пройдено).
- Звіт скомпільовано на рівно 10 сторінок у форматі PDF (Times New Roman, стандарти ЛНУ).

### [Лабораторна робота №2: Rossmann Sales Forecasting Pipeline](lab2/app_sales_forecasting/)
- Розробка повноцінного мікросервісного конвеєра прогнозування щоденного виторгу 100 магазинів мережі Rossmann.
- FastAPI мікросервіс з підтримкою синхронного навчання трьох моделей (Random Forest, LightGBM, Keras MLP), точкового та пакетного інференсу, валідації та сценарного прогнозу.
- Суворе усунення витоків даних: `Customers` виключено з простору ознак, `logMonthSales` перераховано строго з train, дні закриття магазинів (`Open == 0`) строго повертають прогноз `0.0`.
- Streamlit вебінтерфейс (4 сторінки на Plotly: EDA, Model Training, Model Comparison, Forecasting & Scenario Simulation) взаємодіє виключно через REST API.
- Набір автоматизованих тестів pytest (13/13 успішно пройдено).
- Звіт скомпільовано на рівно 10 сторінок у форматі PDF (Times New Roman, стандарти ЛНУ).
